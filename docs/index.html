把参数变成直觉

拖动右侧参数，观察取景画面和光路同时变化。手机上，参数面板位于画面下方。

  1. 试试光圈：将 f/2.8 调到 f/16，观察远处拱门逐渐清晰。
  2. 比较焦距：先保存 A 组，再改变焦距，开启对比并拖动分界线。
  3. 理解透视：固定机位改变焦距只改变取景范围；勾选“保持主体大小”会移动机位，背景与主体的大小比例随之改变。
  4. 观察运动：切换“枝头小憩”，点击“观察振翅”并降低快门速度。使用 S 模式可自动匹配光圈与 ISO。

景深采用全画幅、0.03 mm 弥散圆估算。虚化与噪点为教学近似；慢快门通过多时刻鸟姿态叠加展示运动模糊。鸟与栖木在 Blender 中建模，网页加载导出的网格与动作；远景树林为程序生成。曝光模式按场景亮度匹配参数，达到范围限制时可能无法完全补偿。

快门会改变运动拖影；动画本身仍连续播放，单次曝光的区别可以通过保存画面观察。摄像头拍照会保存预览帧，不保证与手机原生相机画质一致。
