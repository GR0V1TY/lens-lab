# 镜头实验室 · Lens Lab

适配电脑和手机的摄影原理交互 Demo，通过三维场景体验焦距、光圈、快门、ISO、对焦、白平衡与机位的变化。

## 功能

- 日光静物、枝头小憩、蓝调高原三个场景。
- 鸟与栖木使用 Blender 导出模型，具有停栖、转头、眨眼和振翅动作。
- 鸟场景支持 24–600mm；高原场景支持远距离及无穷远对焦。
- 环绕、平移、自由漫游、手机双指控制；摄影师模型与视野范围显示机位。
- 保存 A/B 参数与机位进行同步对比；支持 PNG 导出。
- 浏览器真实摄像头预览、设备选择、倒计时拍照。图像只在浏览器本地处理。

## 本地运行

安装 Node.js 18 或更新版本后，运行：

```sh
node server.mjs
```

打开服务输出的 localhost 地址。Windows 也可双击 `启动Demo.cmd`。模型资源需通过 HTTP/HTTPS 加载，不能直接双击 HTML 文件运行。

## GitHub Pages 发布

静态网页与所有资源位于 `docs/`。在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支 `main`、目录 `/docs`。提交到 main 后会自动更新公开站点。

应用使用相对资源路径，支持 GitHub Pages 仓库子路径。`.nojekyll` 保证静态文件直接发布。Pages 提供 HTTPS，可用于浏览器摄像头权限请求。

## 操作

左键拖动环绕、右键或 Shift 拖动平移、滚轮前后移动。自由漫游模式下先点击画面，再使用 WASD 移动、Q/E 升降。手机单指旋转、双指平移、捏合前后移动。轻点画面对焦。

展开“机位示意”查看摄影师与主体的位置关系；拖动示意图只旋转辅助视角。A、B 分别保留机位和参数。

## 模拟范围

本应用为风格化摄影教学模拟。景深按全画幅和 0.03mm 弥散圆估算；虚化、噪点与有限时间采样为近似效果，阴影不积分整段快门曝光。地形不是地理实测数据，自由移动没有碰撞检测。摄像头参数受设备与浏览器能力限制，不保证原生相机画质。

自动化检查覆盖三维渲染、曝光、对焦、机位、A/B、响应式与虚拟摄像头；实体手机帧率与物理摄像头仍需实机验证。
